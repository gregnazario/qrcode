Content types

Each type validates your input and encodes the standard payload the receiving app expects — a WiFi code opens network settings, a vCard adds a contact, a calendar event offers to save the date.

WiFi passwords and contact fields keep their special characters — the correct escaping is applied for you.

Styling guide

Colors & gradients

Foreground colors the modules (and the eyes, unless you override them); background can be a color or transparent (transparent is best reserved for placing the code on a light surface yourself). Enable a gradient from foreground to a second color — linear (with an angle) or radial.

Shapes

Shape sets the module style: square, rounded, dots (with radius slider), or classy (two diagonally opposite corners rounded). Eye sets the three finder patterns independently: square, rounded, circle, or leaf. Circle and rounded eyes include tiny corner tabs — that's deliberate (see scanner safety); tick decorative for pure shapes without them.

With auto eye color, the eyes follow your foreground or gradient; untick it to set a separate eye ring color.

Logo

Upload a PNG or JPEG. The logo is centered, modules underneath it are cleared (not overdrawn), and error correction automatically bumps to the highest level so the code still scans. Keep the size within the validated range (10–33% of the code).

ECC & margin

ECC (error correction) trades capacity for damage tolerance: low 7% → high 30% recoverable. Quartile is the default; a logo forces high. Margin is the quiet zone around the code — 4 modules is the spec recommendation; smaller margins can hurt scanning.

Scanner safety

Every built-in style is held to a machine-checkable standard: the generator's test suite renders each style combination and decodes it back with a real QR decoder, requiring the exact original content. The visual defaults follow from that:

  • Why the tabs on circle eyes? a perfect circle can't cover a finder pattern's corners, and decoders need them — the tabs complete the pattern.
  • Decorative mode removes the tabs and uses bigger corner radii. Phones are often forgiving; strict scanners are not. Test your target scanner before printing decorative codes.
  • Dots below 0.4 radius also warn — smaller dots can drop below decoders' tolerance.
  • Contrast: keep gradients dark enough that modules stay clearly darker than the background.

Command-line equivalents

Everything here is also scriptable with the Rust CLI:

# install:  cargo install --path crates/qrkit-cli

qrkit url "https://example.com" \
  --shape dots --eye circle \
  --fg "#0d47a1" --gradient linear --gradient-to "#42a5f5" \
  --logo logo.png -o poster.pdf

qrkit wifi --ssid "Cafe Guest" --password "latte-2026" -o menu.eps
qrkit vcard --name "Ada Lovelace" --email ada@example.com -o card.svg

# terminal formats (auto-detects kitty / iTerm2 / sixel / half-blocks):
qrkit url "https://example.com" --format auto
qrkit url "https://example.com" --format png --px 32 -o qr.png

Full flag reference, payload formats, and the library API: qrkit documentation.
